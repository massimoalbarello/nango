## Overview

Context Use Agent Sync is an internal provider used by the Context Use CLI to copy local agent conversations into self-hosted Nango Records.

The provider does not require third-party credentials. Run `context-use agent-sync install` from the Context Use deployment directory to create its connection, install the local daemon, and configure its connection-scoped ingestion credential.

Nango administrators can inspect the integration, connection, sync runs, and records in the Nango dashboard. Installation credentials are managed by the Context Use CLI and must not be entered in the dashboard.
